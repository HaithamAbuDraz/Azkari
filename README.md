# Azkari (أذكاري — روضة الأذكار والأدعية)

[![JavaScript](https://img.shields.io/badge/JavaScript-F7DF1E?logo=javascript&logoColor=black)](https://developer.mozilla.org/en-US/docs/Web/JavaScript)

A comprehensive Islamic website featuring morning and evening supplications, prayers, supplications before sleep, and various authentic supplications from the Quran and Sunnah. The site includes interactive counters, progress tracking, a digital rosary, and a sleek, responsive design with a primarily Arabic user interface.

---

## ✨ Features

| Feature | Description |
|---------|-------------|
| 🌅 **Morning Adhkar** | Complete morning supplications with authentic references |
| 🌙 **Evening Adhkar** | Evening protections and remembrances |
| 🕌 **Prayer Adhkar** | Post-prayer supplications and Tasbih |
| 😴 **Sleep Duas** | Bedtime and waking up remembrances |
| 📿 **Various Dhikr** | General daily remembrances and blessings |
| 🔢 **Smart Counters** | Track your progress for each Dhikr |
| 📊 **Progress Tracking** | Visual progress bars for each category |
| 📿 **Digital Tasbih** | Built-in counter for general Tasbih (33/100 milestones) |
| 📱 **Fully Responsive** | Works perfectly on mobile, tablet, and desktop |
| 🕋 **Time-Based Suggestions** | Automatically suggests relevant category based on time |
| 🔔 **Toast Notifications** | Feedback when completing Dhikr or reaching milestones |
| ⌨️ **Keyboard Support** | Press Spacebar for Tasbih |
| 📖 **Authentic Sources** | All Adhkar from Sahih Hadith (Bukhari, Muslim, Abu Dawud, etc.) |
